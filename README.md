# Bobby Anthene — Portfolio

Personal portfolio of Bobby Anthene: projects, blog posts and press coverage. Live at [bobby-anthene.me](https://www.bobby-anthene.me).

Built with Next.js and [Once UI](https://once-ui.com), based on the [Magic Portfolio](https://github.com/once-ui-system/magic-portfolio) template.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where things live

- `src/resources/content.tsx` — profile, About page, skills, achievements, press items
- `src/resources/once-ui.config.ts` — domain, enabled pages, theme
- `src/app/work/projects/*.mdx` — project pages
- `src/app/blog/posts/*.mdx` — blog posts
- `public/images/press/` — newspaper clippings
