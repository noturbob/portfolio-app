## Overview
An end-to-end machine learning pipeline that predicts food delivery times from 56,556 records, along with SQL operations analysis of peak hours and weather/traffic impact.
## Key Features
- **Feature engineering**: 37 engineered features.
- **Model**: Random Forest Regressor with R² = 0.9477 and a mean absolute error of 1.70 minutes.
- **Accuracy in practice**: 99.51% of 11,399 test predictions landed within ±5 minutes of the actual delivery time.
- **SQL analytics**: 23 queries with exported results, plus Tableau visualizations.
## Technologies Used
- **Python, pandas, scikit-learn, SQL, Tableau**.
