## Overview
A lightweight Java application for restaurant billing, with both a simple Swing GUI and an interactive terminal CLI, set up to open directly in Apache NetBeans.
## Key Features
- **Swing GUI**: Menu selection, a live order table, and a real-time breakdown of subtotal, discount, GST (5%), service charge (10%) and grand total, behind a login gate.
- **Terminal CLI**: A numbered menu with continuous order entry and instant receipt printing.
- **Domain logic**: Duplicate items merge into one line, and input validation guards against negative, non-numeric or empty orders.
- **Unit tests** covering subtotals, merging, tax, discount, service charge and receipts.
## Technologies Used
- **Java, Swing, Maven, JUnit**.
