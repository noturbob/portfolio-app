## Overview
My personal Arch Linux setup, built around modern Wayland tools and a minimal aesthetic.
## What's Inside
- **Window manager**: niri (scrollable tiling)
- **Bar**: waybar
- **Terminal**: kitty
- **Launcher**: fuzzel
- **Notifications**: mako
- **System info**: fastfetch
- **Editor**: vim
- **Theme**: GTK 3 and curated wallpapers
