## Overview
The official landing and registration platform for Innovesta 2026, the college's flagship event, structured for multiple contributors to work on at once.
## Key Features
- **Landing page** with custom sections (hero, navbar, event cards).
- **Registrations** handled by Server Actions and stored in SQL.
## Technologies Used
- **Next.js (App Router), TypeScript, Tailwind CSS v4, shadcn/ui, SQL**.
