## Overview
An end-to-end analysis of student academic performance for Semester V, run from a single master script.
## Key Features
- **Data exploration and cleaning**: Quality assessment, normalization and transformation of raw JSON results.
- **Database**: A SQLite schema with 12+ analysis queries.
- **Statistics**: Statistical testing in R.
- **Visualizations**: 14+ charts with Matplotlib and Seaborn.
- **Machine learning**: SGPA prediction and at-risk student classification.
## Technologies Used
- **Python, R, SQL (SQLite), scikit-learn, Matplotlib, Seaborn**.
