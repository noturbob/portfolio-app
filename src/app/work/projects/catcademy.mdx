## Overview
Catcademy is a full-stack platform for CAT exam preparation, with interactive learning, mock tests and performance analytics.
## Key Features
- **Frontend**: 21 routes and 41 components built with the Next.js App Router, with Zustand for state.
- **Backend**: A Go API server with configuration, database migrations, services/handlers/models layers and Docker Compose for the database.
## Technologies Used
- **Next.js, TypeScript, Tailwind CSS, Zustand**: Frontend.
- **Go, Docker**: Backend.
