## Overview
Matinee is a cross-platform, real-time watch party app. It's designed to target 10k initial users across Web, iOS, Android, Windows, Mac and Linux — all sharing one unified backend.
## Key Features
- **Real-time watch parties**.
- **Gamification**: Guild systems, event-based collectables and a leaderboard.
- **Ad marketplace**.
## Technologies Used
- **TypeScript**.
