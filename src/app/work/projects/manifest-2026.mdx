## Overview
Manifest 2026 is a cinematic affirmation dashboard — built to replace flat productivity tools with an immersive experience using spatial design, deep blurs, parallax tilt and ambient lighting.
## Key Features
- **Glassmorphism UI** with noise textures, backdrop filters and ambient gradients.
- **Physics-based motion**: Cards respond to the mouse with Framer Motion parallax.
- **Secure core**: JWT authentication with bcrypt and protected API routes.
- **Optimistic UI** with Zustand for instant state updates.
- **Fully responsive**, with a custom mobile drawer.
## Technologies Used
- **React, TypeScript, Tailwind CSS, Framer Motion**: Frontend on Vercel.
- **Node.js, Express, MongoDB**: Backend on Render.
