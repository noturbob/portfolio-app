## Overview
Syncboard is a full-stack whiteboard where every stroke is broadcast to all participants instantly.
## Key Features
- **Real-time collaboration**: Draw, add shapes and see other users' cursors move live over WebSockets.
- **Toolbar**: Pencil, eraser, line, rectangle and circle tools with adjustable color and brush size.
- **Secure auth**: Registration, login and password recovery with JWT, plus a Redis-backed token blacklist for real logouts.
- **Autosave**: Boards save to MongoDB after a pause in drawing.
- **Invite links**: Unique "Co-board" links start private multi-user sessions.
## Technologies Used
- **React, Tailwind CSS, Framer Motion, Socket.IO client**: Frontend.
- **Node.js, Express, MongoDB, Socket.IO, Redis, JWT**: Backend.
